About the Project

Our project is an advanced AI-powered Handwritten Text Recognition (HTR) system that combines CNN, Vision Transformer (ViT), and LSTM architectures to accurately recognize multilingual handwritten text. CNN extracts visual features, ViT captures global contextual information, and LSTM learns sequential patterns for improved text prediction. Built with PyTorch and Flask, the system delivers fast, reliable, and real-time OCR performance for document digitization, educational applications, intelligent automation, and historical manuscript preservation.
